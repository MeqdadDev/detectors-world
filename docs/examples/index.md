# Examples

Each example is a complete program. Their code lives in the [`examples` folder](https://github.com/MeqdadDev/detectors-world/tree/main/examples) of the repository, and this site shows the same files.

To run them, get a copy of the repository and install the package:

```bash
git clone https://github.com/MeqdadDev/detectors-world.git
cd detectors-world
pip install detectors-world
```

Webcam examples quit when you click the video window and press ++q++.

## Getting started

| Example | What it shows | Detector |
|---|---|---|
